# 列表（list）

## 创建与索引
```python
a = [1, 2, 3, "x"]      # 可以混不同类型
a[0]     # 1    第一个（下标从 0 开始）
a[-1]    # "x"  最后一个（负数倒着数）
a[1:3]   # [2, 3]  切片：下标 1 到 2（不含 3）
```

## 常用方法

| 方法 | 作用 | 例子 |
|---|---|---|
| `append(x)` | 末尾加一个 | `a.append(4)` → `[1,2,3,4]` |
| `insert(i,x)` | 在下标 i 处插入 | `a.insert(0,0)` → `[0,1,2,3]` |
| `extend(列表)` | 末尾拼上另一个列表 | `a.extend([4,5])` |
| `pop(i=-1)` | 弹出下标 i 的元素（默认最后），返回它 | `a.pop()` |
| `remove(x)` | 删除第一个等于 x 的 | `a.remove(2)` |
| `index(x)` | 返回 x 的下标 | `a.index(3)` |
| `count(x)` | 数 x 出现几次 | `a.count(1)` |
| `sort()` / `sort(reverse=True)` | 升序/降序排序 | `a.sort()` |
| `reverse()` | 原地倒序 | `a.reverse()` |

## 常用内置函数配合列表
```python
len(a)            # 长度
sum([1,2,3])      # 求和 → 6
min(a) / max(a)   # 最小 / 最大
sorted(a)         # 返回新排序列表（不改原列表）
3 in a            # 判断 3 在不在列表里 → True/False
```

## 遍历（两种）
```python
for x in a:                  # 直接拿元素
    print(x)

for i, x in enumerate(a):    # 拿下标 + 元素（常用！）
    print(i, x)
```

## 列表推导式（高频 ⭐）

一行生成列表：
```python
[i*2 for i in range(5)]              # [0,2,4,6,8]
[i for i in range(10) if i%2==0]     # [0,2,4,6,8] 带条件
[x.upper() for x in ["a","b"]]       # ['A','B'] 对元素加工
```

## 列表 ↔ 字符串（CTF 常用）
```python
"a-b-c".split("-")        # ['a','b','c']   字符串 → 列表
"-".join(['a','b','c'])   # 'a-b-c'         列表 → 字符串
list("hello")             # ['h','e','l','l','o'] 逐字符拆
```

## 注意（新手坑）

- `sort()` / `reverse()` 是**原地修改**，返回 `None`；`sorted()` 才返回新列表
- 切片 `a[:]` 是复制一份；`b = a` 只是给同一个列表换个名字（改 b 会动 a）
