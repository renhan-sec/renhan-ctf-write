# 字符串

## 字母大小写替换

例：`x="i love XuYuan"`

|方法|作用|效果|
|---|----|----|
|capitalize|将字符串的首字母变为大写其他变为小写|`x.capitalize()="I love xuyuan"`|
|casefold|将字符串中字母全变为小写|`x.casefold()="i love xuyuan"`|
|title|将字符串中每个单词的首字母都变为大写|`x.title()="I Love Xuyuan"`|
|swapcase|将字符串中字母的大小写调换|`x.swapcase()="I LOVE xUyUAN"`|
|upper|将字符串中字母全变为大写|`x.upper()="I LOVE XUYUAN"`|

## 左中右对齐

|方法|作用|
|---|----|
|center(width,fillchar=' ')|居中对齐，左右用fillchar填充，默认为空格|
|rjust/ljust(width,fillchar=' ')|靠右/左对齐，左/右边用fillchar填充，默认为空格|
|zfill(width)|左边用0填充到指定宽度|

## 查找

|方法|作用|
|----|----|
|count(sub[,start[,end]])|查询目标字符串在字符串中出现的次数|
|find/rfind(sub[,start[,end]])|查询从左往右/从右往左第一个目标字符串在字符串中的下标索引(查询不到目标输出-1)|
|index/rindex(sub[,start[,end]])|查询从左往右/从右往左第一个目标字符串在字符串中的下标索引(查询不到目标报错)|

## 替换

|方法|作用|
|----|----|
|expandtabs()|将tab替换成空格|
|replace(old,new,count=-1)|将字符串进行替换，count默认为-1，即全部替换|
|translate(table)|能够将一个字符串按照table规则进行变化|
对于translate(table)的详细介绍:首先用str.maketrans(x[,y[,z]])方法来获取一个转换规则的表格table，再按照table的规则translate字符串。
示例：
```python
table=str.maketrans("ABCDEFG","1234567")
"I LOVE XUYUAN".translate(table)
="I LOV5 XUYU1N"
```
或者也可以写成：
```python
"I LOVE XUYUAN".translate(str.maketrans("ABCDEFG","1234567"))
```

## 判断

|方法|作用|
|----|----|
|startswith/endswith(prefix[,start[,end]])|判定参数指定的子字符串是否出现在指定的开始/结束位置|
|isalpha()|判断字符串里是否都是字母|
|isspace()|判断字符串里是否都是空格|
|isupper()|判断字符串里是否都是大写字母|
|isnumeric()|判断字符串里是否都是数字(接受各种数字格式)|
|isidentifier()|判断变量名是否合法(不能有空格，不能以数字开头)|

## 截取

|方法|作用|
|----|----|
|rstrip/strip/lstrip(chars=None)|截掉留白部分 r=右边，l=左边，strip是将左右留白全截掉|
|removeprefix/suffix()|截掉开头/末尾指定的字符串|

## 拆分&拼接

|方法|作用|
|----|----|
|partition/rpartition()|从左往右/从右往左找到一个指定的分隔符，并返回由左右两边内容加上分隔符组成的三元组|
|split/rsplit()|从左往右/从右往左找到指定的分隔符，按照指定次数进行分割|
|join()|示例:
```python
" ".join(("love","xuyuan"))
='love xuyuan'
```
