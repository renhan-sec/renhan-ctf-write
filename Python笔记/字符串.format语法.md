# 格式化字符串

## 对应替换
```python
"1+1={},2的平方是{},3*3={}".format(1+1,2*2,3*3)
>>>'1+1=2,2的平方是4,3*3=9'
```

## 使用下标索引替换
```python
"{0}要一直爱着{1}".format("我","徐愿")
>>>'我要一直爱着徐愿'
"{1}要一直爱着{0}".format("我","徐愿")
>>>'徐愿要一直爱着我'
```
#### 同一个索引值可以被引用多次
```python
"{0}{0}{1}{1}".format("是","非")
>>>'是是非非'
```

## 利用关键字索引
```python
"我的{name}是{x}".format(x="任翰",name="名字")
>>>'我的名字是任翰'
```

## f-string（更常用，优先用它）
```python
name = "任翰"
f"我的名字是{name}"          # '我的名字是任翰'
"我的名字是{}".format(name)  # 老写法，知道即可
```

# 格式化选项语法

语法：`f"{内容:选项}"`，冒号后面是规则。

## 1. 数字精度 `:.2f`
```python
f"{3.1415926:.2f}"   # '3.14'   保留2位小数
f"{3.1415926:.0f}"   # '3'      取整
f"{100:.2f}"         # '100.00'
```

## 2. 千分位 `:,` 和百分比 `:%`
```python
f"{1000000:,}"       # '1,000,000'
f"{0.25:.1%}"        # '25.0%'
```

## 3. 进制转换（CTF 最常用 ⭐）
```python
f"{255:b}"           # '11111111'  二进制
f"{255:x}"           # 'ff'        十六进制（小写）
f"{255:X}"           # 'FF'        十六进制（大写）
f"{255:#x}"          # '0xff'      带前缀
f"{255:o}"           # '377'       八进制
```

## 4. 对齐与填充
```python
f"{'hi':>10}"        # '        hi'  右对齐，总宽10
f"{'hi':<10}"        # 'hi        '  左对齐
f"{'hi':^10}"        # '    hi    '  居中
f"{5:0>3}"           # '005'         用0填充到3位
f"{'hi':*^8}"        # '***hi***'    用*填充居中
```

## 5. f-string 里可以直接放表达式
```python
x, y = 3, 5
f"{x}+{y}={x+y}"     # '3+5=8'
f"{'hello'.upper()}" # 'HELLO'
```

## 6. 两个小技巧
```python
f"{x=}"              # 'x=3'   Python 3.8+ 调试语法，连变量名一起打印
f"{{}} 是花括号"      # '{} 是花括号'  想输出大括号就写两遍
```
